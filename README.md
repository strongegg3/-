# 乐之笛 | Vlog 配乐多智能体平台

> 帮助 vlogger 和剪辑师从模糊的想法出发，用多个协作的智能体推导出完整需求，然后给出候选配乐清单与匹配理由。

## 功能

1. **规划 Agent（Planner）**：一轮一轮澄清你的画面、情绪、节奏、曲风与限制条件，生成可编辑的需求摘要。如果配置了大模型 API，会调用它进行更自然的对话；否则自动回退到本地规则模拟。
2. **音乐寻找 Agent（Finder）**：基于需求摘要提取关键字、情绪、场景与 BPM / 能量区间，在本地曲库中筛选候选曲目并打分。
3. **音乐分析 Agent（Analyst）**：把每条候选曲目按曲风、情绪、节奏、结构、平台来源进行标注，解释推荐理由。
4. **反馈与微调 Agent（Feedback）**：当你说“太吵了”“节奏更卡点”“想要更悲伤一点”时，它会自动修正需求权重，让音乐寻找 Agent 重新排序。

## 目录结构

```
work/
├── index.html              # 页面骨架（结构 + 挂载脚本）
├── styles.css              # 全部 UI 样式（侧边栏、对话、歌单卡片、响应式）
├── README.md
└── js/
    ├── config.js           # 常量（存储 key、默认模型、问题队列、预设反馈）
    ├── catalog.js          # 曲库数据（标题、艺术家、BPM、能量、情绪、场景、平台）
    ├── profile.js          # 关键字提取 / 情绪 / 场景 / BPM 与能量区间推断
    ├── planner.js          # 规划 Agent：LLM 调用 + 本地回退 + 需求摘要生成
    ├── finder.js           # 音乐寻找 Agent：候选筛选与打分
    ├── analyst.js          # 音乐分析 Agent：输出匹配点与推荐结构
    ├── feedback.js         # 反馈与微调 Agent：自然语言反馈 → 权重修正
    ├── state.js            # localStorage 持久化：任务列表、模型配置
    ├── render.js           # 纯 DOM 渲染（不包含业务逻辑）
    └── main.js             # 事件绑定 + 应用启动
```

## 使用方式

直接用浏览器打开 `index.html` 即可。

1. 在页面输入模糊想法（例如“城市夜景 vlog，一个人下班后穿过街区”）。
2. 点击 “发送给规划 AI”，或点击 “载入城市夜景示例” 直接体验。
3. 几轮对话后，规划 Agent 会在右侧生成完整需求摘要；你可以直接修改摘要文本。
4. 点击 “确认需求并生成歌单”，音乐寻找与分析 Agent 会输出 Top 5 候选曲目。
5. 在下方反馈区点预设标签，或输入如“太吵了，想要更悲伤一点”，Agent 会重新排序。

## 可选：接入真实大模型

在侧边栏“模型配置”里填入：

- **Base URL**：例如 `https://api.openai.com/v1`
- **Model**：例如 `gpt-4.1-mini`
- **API Key**：你的 API Key（仅保存在浏览器 localStorage）

点击“保存配置”。之后再发送消息时，如果调用成功，顶部会显示“大模型在线”；失败则自动回退到“本地模拟”，保证不会卡住。

## 扩展建议

- **曲库扩展**：编辑 `js/catalog.js` 的 `catalog` 数组，新增曲目即可。关键字词库在 `keywordMap`，可补充更多场景词。
- **接入音乐平台 API**：在 `js/finder.js` 的 `searchCandidates` 里加入对 Spotify / NetEase / YouTube 的搜索（需要做代理或后端转发，避免浏览器跨域），把返回结果合并到当前候选列表。
- **更多 Agent 协作**：在 `js/main.js` 的 `els.confirmSummary` 点击处理器里插入新的 Agent 步骤（例如“封面生成 Agent”“文案 Agent”）。
